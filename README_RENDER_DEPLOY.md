# Kodez Videos Downloader V4 — Render Free

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/kodez-lo/telegram-ai-bot/tree/kodez-render-free-v4-clean)

This branch contains the clean V4 build:
- no admin panel
- no premium system
- 360p / 480p / 720p / 1080p / Best
- direct video download
- audio and thumbnail modes
- live progress, cancel, history, language, queue, retry, cache, cleanup

During the first Render Blueprint deployment, enter BOT_TOKEN when prompted.
Use the bot only for videos you own or have permission to download.

Render Free uses an ephemeral filesystem, so local SQLite history/cache can reset after a sleep/redeploy.
